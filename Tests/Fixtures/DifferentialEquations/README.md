# Differential-equation regression inputs

These files are the small, explicit inputs used by active tests of optional
epsilon-form construction, rational reconstruction, multiquadratic evaluation,
scalar-operator factorization, coordinate changes and integral definitions.
They were extracted from obsolete run directories before those runs were removed.

- Families: validated CF269/CF48 forms and the defining raw systems. Only the
  forms' source-reference paths changed; their mathematics was checked unchanged.
- FactorizedScalarOperators: three epsilon-zero operator factorization examples.
- Multiquadratic: CF259 pairwise radical inputs and the CF300 input/reference channels.
- FiniteFieldBenchmark and FiniteFieldRaw: explicit inputs and sampled data needed
  by the finite-field regression tests.

These are test fixtures, not an old production run or the current solution
inventory. The general production run is
`ppHX_NNLO_DoubleReal/Results/UU_08_10_canonical/Stage1And2_2026-09-06`.

[The removal record](../../../Design/StaleDEResultRemoval_2026-09-06.md)
lists their source paths and the removed directories.

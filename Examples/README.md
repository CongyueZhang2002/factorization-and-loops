# Examples

[Transport/README.md](Transport/README.md) documents the general epsilon-order
requests, automatic normalization and finite-solution constructor.

Small symbolic examples are self-contained. The stored-family example reads
the current all-family DE run and sends it through the same general constructor;
the family names are demonstration inputs. Output goes to a caller-selected
scratch directory, not to this source tree.

The small saved order-planner result illustrates the example output. It is not
a production input or an alternative stored DE solution.

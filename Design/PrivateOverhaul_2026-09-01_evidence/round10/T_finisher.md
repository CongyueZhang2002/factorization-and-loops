## Findings on the inputs (before any code)

1. **Leaked symbols.** The 39 of 40 round-9 endpoint records with `FeynFacetCampaign`PhysicalBoundary`Private`endpointVariable$NNN` / `localCoordinatePower$NNN` got them from two `HoldForm[...]` expressions in `Scripts/Transport/PhysicalBoundaryCampaignAdapter.wl` (`RequiredLocalNormalization`, `NontrivialModesRequire`): a `HoldForm` over Module locals writes the locals' renamed symbols into the stored record. Fixed at the source: the values are inserted with `With` before the `HoldForm`, and the unqualified `R` (which was `...`Private`R`) is now the string "R". The finisher's purity check refuses any symbol whose name contains `$` or whose context contains `Private``.
2. **The automaton's state is the canonical Laurent-slot vector at the target point.** Verified on CF97 (`round10/probe_cf97_automaton.log`): `InitialDemandMap` equals, entry by entry, the functional slot (p, k) -> coefficient of eps^(n-p) in `TTotal[[r, k]]` over the 78 ambient slots for all four demanded pairs, and every letter matrix lowers the slot order by exactly one. Consequence: a unit slot functional yields any canonical row's expansion from the same automaton, which is what the DE certificate needs (the DE couples the physical rows to every other row).
3. **The graded endpoint records freeze the T prefactor at the interior base.** `ComposeGradedPhysicalEndpointWords` specializes every current word map at `CurrentBaseRules` (`endpointSpecializeMatrix[wordResult, baseRules]`), so the round-9 records represent the demanded outputs at the interior base point only: the (x, y)-dependent transformation T (the `InitialDemandMap`) is evaluated there. That is right for the boundary constants at the base (Codex's purpose) but it is not a representation of the target dependence; a finished record built by composing the physical graded record would carry constant coefficients where the true ones are rational functions of the target (found on CF97: -24 P1 + 216/5 P3 versus P1/(x y (x y - x - y)) - 3 P3/(2 x y (2 x y - x - y)) at order 0, row 17). The finisher therefore assembles the physical rows exactly as I_r^(n) = Sum_(p,k) T^(n-p)_(r k) F_k^(p) from the canonical expansions and uses the graded record only where it is valid: coefficient by coefficient at the interior base (certificate `GradedRecordConsistency`).

## The finisher

`FeynFacet/Private/Transport/Boundary/FinishPhysicalTransport.wl` (manifest entry after `PhysicalBoundary.wl`; usages in `FeynFacet.m`): `FinishPhysicalTransport[family, options]`, `PhysicalTransportFinishedQ[record]`. Stages, per the contract:

- inputs: certified eps-form, accepted observable transport (round-9 directory, fallback the 2026-09-01 set), boundary-mode map (round-9, fallback canonical), graded endpoint record (round-9, fallback canonical); the files are recorded and fingerprinted.
- legs and letters: the four legs outermost first -- CurrentFirst (x from x0 to the target x, the target's y symbolic in the letters), CurrentSecond (y from y0 to the target y at x = x0), EndpointFirst, EndpointSecond (from the physical endpoint to the interior base, the mode map's edge data as the tangential prescription); every dlog kernel is converted to explicit base letters {"GPLPole", c} / {"GPLFactor", q, k} with its residue as a coefficient (the transport's first-leg kernels are re-expressed from the path parameter to the family variable).
- canonical expansions: the word pairs with a nonzero map are enumerated on the unit slot functionals (exact rational matrices, pruning on exact zero maps), composed through a canonical graded binding built in memory (known-zero periods passed as the endpoint mission passes them), and collected into tables {word, period} -> coefficient.
- physical rows: I_r^(n) = Sum T^(n-p)_(r k) F_k^(p), explicit rational-function coefficients over the named period symbols `FeynFacetPeriod`<family>`Pj`.
- period table: definition (family, stratum, edge point, chart, Frobenius mode, integer valuation, ledger id), status Exact / KnownZero (census certificate `period_NN.wl`, proof record) / Transferred (`TransferResults.wl`) / Unevaluated; relations: known values and degenerate-eigenspace declarations; independent unknown count.
- certificate (i): for every canonical slot, d_x F^(p) = A_x F^(p-1) at a generic point and d_y F^(p) = A_y F^(p-1) on the line x = x0, as word-by-word identities of rational functions (exact `Together`, or evaluation at random points modulo fresh primes for dimension above 24); absent lower slots must lie below the certified block valuation; with the certified flatness this proves the DE everywhere.
- certificate (ii): the empty-word coefficient of every canonical slot equals the mode vectors' eps coefficients.
- certificate (iii): fingerprints of the four inputs and the demand; purity of every stored expression (only the documented heads, the family variables, rationals and the period symbols).
- `PhysicalTransportFinishedQ` re-runs (i), (ii), the purity check and the base-point consistency from the record alone (the connection, the mode vectors, the T functionals and the graded record's base terms are stored).

# Single-inclusive NLO q q′ → q + X

The calculation uses the general FeynFacet amplitude, reduction, analytic-integral,
endpoint-distribution and counterterm workflow. UU is unpolarized. LL and TT
polarize **both incoming quarks**, with unpolarized fragmentation D1.

## Run

From the repository in WSL:

```sh
wolframscript -file Scripts/run_nlo_hard_function.wls ppHX_NLO_qqprime UU_Campaign all
wolframscript -file Scripts/run_nlo_hard_function.wls ppHX_NLO_qqprime LL_Campaign all
wolframscript -file Scripts/run_nlo_hard_function.wls ppHX_NLO_qqprime TT_Campaign all
```

`all` generates the complete diagram sets, reduces nonzero contributions, constructs
analytic master values at automatically determined epsilon orders, generates the
necessary Born channels and counterterm cards, and assembles the finite result.
`assemble` reuses existing amplitude/reduction records. It still regenerates Born
counterterms and analytic master/distribution values. Use `all` after changing the
amplitude conventions, process, normalization or reduction code.

Each campaign card identifies a Born, real and virtual card. Collinear channels
are enumerated from nonzero splitting and explicitly supplied finite kernels.
For this channel, the off-diagonal incoming-B subtraction requires qg → qg Born.
The counterterm Born channel's own spin and color averages are used. No FF
counterterm is attached to the unobserved recoil.

## Mathematica results

- `Results/UU_HardFunction.wl`
- `Results/LL_HardFunction.wl`
- `Results/TT_HardFunction.wl`

These are ordinary Mathematica associations containing explicit expressions.
They require no FeynFacet package to read. They contain no unevaluated master
integral, integration call, recurrence or numerical generator.

```wl
result = Get["Results/UU_HardFunction.wl"];
nlo = result["PerturbativeTerms"]["NLO"];
nlo["DeltaCoefficient"]
nlo["PlusCoefficients"][0]
nlo["PlusCoefficients"][1]
nlo["RegularCoefficient"]
```

The coefficients multiply δ(1-w), [1/(1-w)]₊,
[log(1-w)/(1-w)]₊ and the regular term, respectively. `LO` contains the Born
coefficient. The physical density is E_c dσ/d³p_c, with
v=1+t/s and w=-u/(s+t). The physical powers α_s² and α_s³ are included.
CA is the number of colors; CF=(CA²-1)/(2 CA) has been substituted. The number
of massless quark flavors is nU+nD. Renormalization and factorization scales
are muR2, muFA2, muFB2 and muD2, all squared scales.

The plus distributions have their full endpoint mass on [0,1]; test functions
exclude w=0 and the tangential boundaries v=0,1. This is the usual partonic
threshold convention appropriate to convolution with a positive hadronic lower
limit. Distinct incoming-flavor TT is exactly zero in D dimensions before IBP;
its azimuth was never averaged away.

## Counterterm schemes

UU uses MSbar. Each incoming helicity quark in LL uses HelicityMSbar, including
the BMHV restoration Zqq=-4 CF(1-xi). The observed FF is unpolarized MSbar.
A single generated counterterm card may supply an explicit `FiniteKernel`
association with `Variable`, `DeltaCoefficient`, `PlusCoefficients` and
`RegularCoefficient`. Its sign follows f_new=(1+α_s Z/(2π))⊗f_old; the hard
coefficient changes by -α_s Z⊗Born/(2π).

For automatic campaign enumeration, specify a matrix for a leg's `Schemes` entry:

```wl
<|"DefaultScheme" -> "MSbar",
  "FiniteKernels" -> <|
    {{"q", "u"}, {"q", "u"}, "U"} ->
      <|"Variable" -> xi, "DeltaCoefficient" -> 0,
        "PlusCoefficients" -> <||>,
        "RegularCoefficient" -> kappa (1-xi)|>
  |>|>
```

Keys are {daughter,parent,spin}. Explicit finite flavor mixing participates in
Born-channel enumeration; the TT zero is not assumed for an arbitrary scheme.
The species map in a campaign declares the flavor basis to enumerate. Additional
finite kernels may include any nonnegative integer logarithmic plus order; the
final merger retains every declared order rather than restricting it to 0 and 1.

interior-only Gauss expansion misses. Deliberately shortening one epsilon order
is rejected. The broader framework checks currently pass 290 assertions across

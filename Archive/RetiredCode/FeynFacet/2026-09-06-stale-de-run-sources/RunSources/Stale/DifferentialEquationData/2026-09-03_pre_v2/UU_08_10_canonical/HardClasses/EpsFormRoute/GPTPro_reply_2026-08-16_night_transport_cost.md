## 1. Exact transport-depth arithmetic
Let the globally ordered canonical blocks satisfy dF_i = eps Omega_i F_i + Sum_{j<i} C_ij(eps) F_j (1), with C_ij(eps) = Sum_r eps^r C_ij^[r] (2), each C_ij^[r] a matrix-valued rational one-form in the exact dlog alphabet. Let B_i(eps) = Sum_n eps^n B_{i,n} (3) be the physical boundary vector of block i. Define W_i(n) = the largest Chen-word length required to determine F_{i,n} (W_i(n) = -infinity when the coefficient does not occur). The exact recursive bound is
   W_i(n) = max{ 0 if B_{i,n} != 0 ; 1 + W_i(n-1) ; 1 + W_j(n-r) for every C_ij^[r] != 0 }   (4)
(second line from the diagonal canonical term eps Omega_i F_i, third from one off-diagonal integration). Equation (4) is the exact generic scheduling rule; it accounts for different boundary valuations, positive- and negative-order couplings, gaps/exact zeros in a boundary series, different requested orders per block, and high-order couplings compensating earlier negative-order ones.
Why the current D overestimates: the code assigns each edge the nonnegative cost max(0, 1 - r_ij) (5) and sums along a path; the exact path contribution is the signed sum |p| - Sum_{e in p} r_e (6). Example r_1 = -3, r_2 = 3: actual extra word length 2, clamped rule 4.
If block boundary series begin at orders b_i with generic consecutive support, Eq. (4) reduces to W_i(n) = n - b_i + D_i (7) with D_i = max[0, max_{j<i}(D_j + 1 - r_ij + b_i - b_j)] (8), equivalently D_i = max over paths p: k ~> i of [0, |p| - Sum_e r_e + b_i - b_k] (9). Use Eq. (4) in production; it is not more expensive than the existing DAG calculation and is strictly sharper.
Map the requested original-basis depth first: with I = T(eps) F (10), T_ai = Sum_t eps^t T_ai^[t], and original master I_a required through order N_a, canonical block F_i is required through at most N_i = max_{a,t : T_ai^[t] != 0} (N_a - t) (11), evaluated entrywise using the actual master coefficients entering the hard function, the actual transformation entries, and exact detection of vanishing leading coefficients. "Every master through roughly eps^4" remains a planning estimate, not the production depth.

## 2. Per-block eps-rescalings cannot lower the intrinsic weight
F'_i = eps^{m_i} F_i (12): b'_i = b_i + m_i, N'_i = N_i + m_i (13), r'_ij = r_ij + m_i - m_j (14); the quantity 1 - r_ij + b_i - b_j in Eq. (8) is invariant (15), and N'_i - b'_i = N_i - b_i (16); therefore W'_i(N'_i) = W_i(N_i) (17). Proposal (a) cannot reduce the exact minimum Chen weight. It can improve implementation (remove explicit eps-poles from intermediate matrices, decrease rational coefficient sizes, let a monolithic routine use a smaller nominal global weight, improve sparsity) — an optimization of representation, not of the intrinsic analytic work.

## 3. The "checkable window" is correct only for the current monolithic residual
With r_min = min ord_eps A_ij, the eps^n coefficient of dI - A I contains A^[r_min] I_{n - r_min}; a direct original-basis residual is available only for n <= n1 - |r_min| (18). That is correct, but it is a requirement of one expensive checking method, not of the solution. Exact recursive certificate: dF_{i,n} = Omega_i F_{i,n-1} + Sum_{j<i} Sum_r C_ij^[r] F_{j,n-r} (19); represent every F_{i,n} as a sparse map (Chen word -> exact rational coefficient); verify (19) by exact differentiation of each word, exact rational differentiation of its coefficient, sparse collection by word, exact zero tests per coefficient. Combined with A = dT T^-1 + T Ahat T^-1 (20) verified exactly once, Eq. (19) proves the original DE without recomputing a huge transformed-back residual at every order: exact gauge identity + exact canonical recursion + exact boundary values => exact original-basis solution (21). No need for three extra orders merely to make a global Together check possible.
Floating-point checks are not a replacement: the proposal to replace exact residuals by high-precision numerical checks should be rejected as the production certificate. AMFlow, DiffExp, GiNaC, or high-precision GPL evaluation remain independent comparisons. If rational simplification is still expensive, use exact finite-field verification, not floating point: clear the known denominator of each word coefficient; evaluate and reconstruct the numerator over finite fields; retain exact degree bounds; require the reconstructed numerator to be the zero polynomial.

## 4. Blockwise transport is the highest-value structural change
Standalone hard 4x4: seconds; 13x13 and 24x24 whole-family Pexps: exceed 1800 s at weights 5-7. The whole-family engine computes too much at once. For each diagonal block dPhi_i = eps Omega_i Phi_i (22); solve recursively F_i = Phi_i [ B_i + Sum_{j<i} Int_gamma Phi_i^-1 C_ij F_j ] (23). At fixed Laurent order this is a sparse Chen-word calculation; no global 24x24 Pexp is required.
Transport only the physical boundary subspace: determine the local boundary constraint matrix; compute its residual nullity q_i; transport only one particular physical solution and q_i unresolved boundary columns (a block of dimension d_i with q_i = 1 overproduces d_i - 1 columns if the full fundamental matrix is transported). Same economy already identified for Class 77.
Does Libra exploit block triangularity? Whether PexpExpansion has an internal sparse/triangular optimization is secondary; the measured whole-family scaling shows it does not exploit the dependency graph sufficiently for production. A wrapper should enforce Eq. (23) explicitly.

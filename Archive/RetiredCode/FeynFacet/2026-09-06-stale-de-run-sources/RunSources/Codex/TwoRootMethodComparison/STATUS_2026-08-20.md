# Two-root epsilon-form method comparison, 2026-08-20

## Acceptance criterion

For every claimed off-diagonal gauge `R` and dlog residues `K_a`, both exact
Pfaffian residuals must vanish as rational functions:

```text
partial_mu R - eps (E_mu R - R C_mu)
  - B_mu + eps sum_a K_a partial_mu log(W_a) = 0,
mu in {1,2}.
```

A family is complete only after composing every required strip and verifying
the full transformed connection. Solving one strip is not a complete family
epsilon form.

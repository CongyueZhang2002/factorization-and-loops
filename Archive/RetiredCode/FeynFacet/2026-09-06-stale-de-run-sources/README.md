# Sources retained from obsolete DE runs

Only source programs and derivation notes are retained here, together with
small pre-edit source/configuration snapshots. They are not loaded by production.
The old numerical and symbolic DE run outputs were deleted, not backed up.

Generated Maple programs consisting of emitted matrix coefficients were treated
as disposable run inputs and removed with the runs.

[The removal report](../../../Design/StaleDEResultRemoval_2026-09-06.md)
records sizes and retained mathematical dependencies. Active regression data
are under `Tests/Fixtures/DifferentialEquations`; CF303's required preparation
is stored with the current 91-family run.

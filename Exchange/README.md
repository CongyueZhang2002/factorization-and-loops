# Codex–Fable exchange archive

Exchange material is grouped first by author, then by date:

```text
Exchange/
  Codex/YYYY-MM-DD/NN_summary_name[.ext]
  Fable/YYYY-MM-DD/NN_summary_name[.ext]
```

`NN` is the sequence number for that author's exchanges on the date. A unit can
be either one file or one directory containing a report and its supporting
artifacts.

This archive was formerly stored at `External/CodexExchange/`. Historical
artifacts are preserved byte-for-byte and may still mention that old path in
logs, scripts, or provenance notes. Those mentions describe the environment in
which the evidence was created; resolve their leading `External/CodexExchange/`
against this `Exchange/` directory when reproducing old work.

New exchanges should be filed directly into the appropriate author/date
directory using the next sequence number and a short content-based name.

## The standard (user policy, effective now)

1. A block may be promoted to the transport-exception route ONLY with a
   mathematical impossibility certificate. Minimum bar: the
   gauge-eliminated integrability screen for that block — witness with
   w^T A = 0, w^T b != 0, verified at two configured plus one fresh
   (prime, regulator) image. This is a minutes-scale computation (it
   scales with letters, not gauge unknowns).
2. Resource/budget refusals NEVER promote. They stop typed and park the
   block for optimization or user decision, like every other stop.
3. Retroactive: run the witness screen on (25,14) now. If it certifies,
   its promotion stands at full grade. If it unexpectedly fails to
   certify, (25,14) returns to the solve queue (enlarged support)
   and its exception record is withdrawn.
4. Prospective: (25,11), (25,1), and any future candidate get the
   screen BEFORE any conversion is prepared.
